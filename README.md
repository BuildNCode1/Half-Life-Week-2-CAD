# 3D Printed Combination Puzzle Box

A custom-designed 3D-printable puzzle box featuring a rotating combination wheel, a locking pin mechanism, and a hidden main drawer. 

---

## Features
* **Combination Lock**: Rotate the wheels to align the correct symbols and unlock the mechanism.
* **Secondary Security**: Requires flipping the box upside down and removing a physical locking pin before the main drawer can be accessed.
* **Hidden Compartment**: Designed to securely store small items once solved.

---

## How to Solve
1. **Find the Combination**: Rotate the combination wheels on the front until the correct code is entered.
2. **Flip and Pin**: Flip the puzzle box upside down and carefully remove the locking pin.
3. **Open**: Slide out the main drawer to reveal the contents inside.
